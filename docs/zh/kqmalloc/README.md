## 项目介绍

本文档适用于KQMalloc V0.22。

KQMalloc是专为鲲鹏处理器设计的并行内存分配器，针对Linux操作系统下4KB和64KB系统页大小、48位内存虚拟地址的系统场景进行了适配与优化。
分配器初始化时按单线程模式运行，检测到第二个线程后自动切换到多线程模式。从V0.21版本开始，KQMalloc不再提供独立的单线程动态库。
KQMalloc使用透明大页等技术，可最大限度地减少页表缓冲未命中、降低缓存碎片和缓存别名问题。

适用场景：内存的申请、释放等。

## 特性介绍

**表1** KQMalloc特性介绍

| 特性名称 | 特性介绍 |
| ------------ | ------------ |
| 多级无锁缓存快速路径 | 每个线程拥有独立的本地缓存，小对象分配仅需10条以内指令，全程无需加锁。未命中时逐级回退到Quick Cache（CAS原子操作的无锁缓存）和Fast Cache（自适应容量的共享缓存）分配。 |
| 大对象原地扩缩 | 大对象realloc通过虚拟内存提交/取消提交（commit/decommit）原地调整大小，避免分配新内存再拷贝。 |
| 精细的大小分级与低碎片堆选择 | 将对象按大小划分为100+级别，小对象以4字节为步进、大对象以缓存行为步进，每次分配匹配最接近的槽位。 |
| 双向堆脏页回收 | 尾部裁剪（tail clean）：当堆驻留超过阈值，通过MADV_DONTNEED释放尾部多余页面。<br>堆压缩（compression）回收尾部虚拟地址空间。<br>中部回收（body clean）：对释放后的中间区域排序合并，向相邻空闲cell扩展以凑齐页面对齐边界后统一释放。 |
